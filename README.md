# ПОСЛЕДНИЕ 180 СЕКУНД (MVP-версия)

Психологический выживальщик с минималистичной геометрической эстетикой.

## Описание

Пространственно-временной коллапс начнётся через 180 секунд. Три фигуры остались в коридоре. Кого вы спасёте?

## Игровая механика

### Управление
- **Мышь** — движение курсора управляет игроком (золотой круг)
- **ЛКМ (зажать)** — взаимодействие с фигурой (установка доверия)

### Таймер
- Обратный отсчёт 180→0 секунд
- **Ускорение +5%** при резком движении мыши (>200px/s)
- **Замедление -3%** при спокойствии (<50px/s)

### Персонажи
| Фигура | Цвет | Роль |
|--------|------|------|
| Треугольник | Красный | Ложь/Агрессия |
| Квадрат | Синий | Правда/Спокойствие |
| Шестиугольник | Золотой | Жертва |

### Механика доверия
- Зажмите ЛКМ рядом с фигурой (>5 секунд) для установки доверия
- При достижении доверия цвет фигуры светлеет
- Прогресс отображается кольцом вокруг фигуры

### Неевклидов коридор
- При прохождении через центр экрана позиции фигур меняются (рандом из 3 пресетов)

### Финал «Сообщество»
- Если игрок установил доверие с ≥2 фигурами — в 00:00 экран заливается белым градиентом
- Иначе — финал «Рассеянность»

## Технические детали

- **Технологический стек**: HTML5 Canvas + JavaScript (ES6)
- **Архитектура**: Единый игровой цикл `requestAnimationFrame`
- **State-машина**: WAKEUP → CORRIDOR → FINALE
- **Визуал**: Геометрические примитивы, пульсация через `Math.sin(time * 3)`
- **Оптимизация**: 60 FPS, адаптивное разрешение

## Запуск

Просто откройте `index.html` в браузере. Не требует сервера или внешних зависимостей.

```bash
# Локальный сервер (опционально)
python3 -m http.server 8000
# или
npx serve
```

## Структура кода

```
index.html          # Полный self-contained HTML-файл со встроенным JS/CSS
game-mvp.html       # Альтернативная версия (копия)
```

### Классы

- `TimerSystem` — управление обратным отсчётом с модификаторами скорости
- `Character` — базовый класс для фигур (треугольник, квадрат, шестиугольник)
- `Game` — основной игровой цикл, рендеринг, обработка ввода

## Философский посыл

Игра сохраняет философский посыл о выборе и времени через геймплей:
- Распределение времени между фигурами = выбор приоритетов
- Резкие движения ускоряют время = паника ускоряет конец
- Спокойствие замедляет время = контроль через внутреннее состояние
