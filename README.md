# ПОСЛЕДНИЕ 180 СЕКУНД

Психологический выживальщик с элементами тактического менеджмента времени, абстрактной визуальной поэзии и морального квеста.

## Описание игры

Игра начинается в 06:57 утра в квартире-модуле. У вас есть 180 секунд (3 минуты) до пространственно-временного коллапса. За дверью коридор с 12 уникальными геометрическими персонажами — каждый со своей формой, цветом и мотивацией.

## Особенности геймплея

- **Обратный отсчёт 180 секунд** — живой элемент, который пульсирует в такт "дыханию" игрока
- **12 уникальных персонажей** — геометрические формы с разными характерами и ролями
- **Динамика времени** — паника ускоряет отсчёт, спокойствие замедляет
- **Неевклидова геометрия** — коридор меняется при повторном прохождении
- **7 разных финалов** — от "Абсолюта" до "Хаоса"
- **Генеративный звук** — все звуки создаются в реальном времени
- **Минималистичный интерфейс** — только обратный отсчёт и визуальная коммуникация

## Управление

- **Мышь** — перемещение игрока (курсор плавно следует за мышью)
- **Клик по персонажу** — взаимодействие
- **Клик по фрактальным углам** — особый эффект (после 3 просмотров останавливает время на 1 секунду)

## Персонажи

1. **Красный Треугольник** — агрессивный, бывший охранник
2. **Синий Квадрат** — спокойный, инженер инфраструктуры
3. **Зелёный Круг** — гипнотический, ботаник-одиночка
4. **Фиолетовая Звезда** — мистик, песня замедляет время
5. **Оранжевая Трапеция** — ПТСР, импульсивный спасатель
6. **Чёрный Ромб** — параноик, почти невидим
7. **Золотой Шестиугольник** — жертвенность, дарит стабильность
8. **Серебряный Цилиндр** — зеркало коллективного бессознательного
9. **Белый Многогранник** — хаос, показывает все исходы
10. **Коричневый Параллелепипед** — несёт на себе свою "семью"

## Создание персонажа

Перед началом игры выберите:
- **Форму** (психологию): Треугольник, Квадрат, Круг, Шестиугольник или Звезда
- **Цвет** (роль в кризисе): Алый (импульсивность), Лазурный (мудрость), Изумрудный (ресурсы), Аметистовый (интуиция), Янтарный (хаос), Золотой (лидерство)

## Финалы

- **Абсолют** — остаться одному в квартире
- **Сообщество** — объединить 5+ фигур
- **Одиночество** — выжить, но бросить Параллелепипеда
- **Бегство** — добраться до улицы
- **Иллюзия** — поверить Фиолетовой Звезде
- **Хаос** — не успеть никому помочь

## Техническая реализация

- **Движок**: HTML5 Canvas + JavaScript (без внешних библиотек)
- **Звук**: Web Audio API, генеративная музыка
- **Визуал**: процедурная генерация геометрии, градиентные шейдеры
- **Производительность**: 60 FPS, оптимизированный рендеринг

## Запуск игры

Просто откройте `index.html` в современном браузере. Никакой сборки или зависимостей не требуется.

Для локальной разработки с автоперезагрузкой:

```bash
# Используя Python 3
python -m http.server 8000

# Или используя Node.js с live-server
npx live-server
```

Затем откройте `http://localhost:8000` в браузере.

## Философский посыл

Игра — не про выживание. Фигуры — архетипы человеческих реакций на конец: страх, рациональность, вера, жертвенность, хаос.

Три минуты — не ограничение, а концентрат жизни. Что вы выберете, когда у вас нет времени на сомнения?
